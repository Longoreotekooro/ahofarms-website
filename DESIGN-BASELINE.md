# AHO FARMS — Website-wide Design Baseline

CEO-issued design system, 2026-09-01. This is the baseline for **all existing
pages and any new pages**. Do not rebuild strong existing components
unnecessarily, but redesign anything generic, flat, repetitive or disconnected
from this system.

The site should feel: **premium · cinematic · grounded in whenua ·
contemporary · Māori-led · cultivation-focused · trustworthy · distinctly Aho.**

> **Master principle**
> Hero = entry point · Background changes = chapter separation ·
> Thread = connection · Photography/video = emotion · Typography = story ·
> Data = credibility · Whitespace = premium feel.
> *Separate chapters. One thread.*
> Every page recognisably Aho Farms even with the logo removed.

## 1 · Every page opens with a strong hero
`[HERO VIDEO — PLACEHOLDER]` or `[HERO IMAGE — PLACEHOLDER]` — large,
cinematic, page-specific. Subjects: flower, cultivation, whenua, Hawke's Bay,
greenhouse, canopy, trichomes, roots, soil, hands, muka, processing, team,
science, environment. No generic stock. Missing asset → labelled placeholder +
developer note describing the final asset.

## 2 · Pages are distinct visual chapters
Deliberate changes of background colour, spacing, composition, imagery, type
scale, section height, density. **Background colour creates separation. The
aho thread creates connection.**

## 3 · Background system (existing palette)
- **Deep charcoal / near black** — strong statements, premium cannabis,
  technical, cultivation, trust/compliance, closings.
- **Warm off-white / flax** — storytelling, history, explanatory, cultural,
  editorial.
- **Natural earth / sand** — whenua, terroir, environment, people,
  cultivation philosophy.
- **Deep Aho green** (selective) — brand-defining, differentiators, proof,
  strong CTAs, transitions.
- **Full-bleed photography/video** — visual breaks between heavy sections.
Never several consecutive sections on the same background.

## 4 · Not a stack of boxes
Refined transitions: imagery overlapping two backgrounds, thread crossing
boundaries, type extending across sections, full-width photography breaks,
subtle tonal gradients, irregular crops, negative space before shifts,
oversized image edges, occasional organic boundaries. Restrained,
architectural.

## 5–8 · The aho thread — master device
Thread = storytelling and navigation device, never a decorative sidebar line.
It may weave, travel between sections, hide behind photography, emerge, split,
reconnect, wrap a statistic, guide the eye, cross colour boundaries, shift
from muka-realistic to abstract, animate subtly on scroll.
- **Colour responds to background:** light bg → charcoal / deep green / muted
  fibre; dark bg → flax / warm beige / soft off-white. Transition subtly.
- **It should sometimes disappear:** appear → guide → slip behind an image →
  vanish → return several sections later. Never top-to-bottom constant.
- **Different expressions per page:** Home = whole story arc. Advantage =
  fibres converging into one thread. Terroir = contours/latitude/soil lines.
  Cultivation = roots / irrigation / rows. Trust = organic thread becoming
  precise (Seed → … → Patient). Story = ancestral (whenua → past → present →
  future). Contact/Tūhono = many threads converging on one point.

## 9–10 · Scroll rhythm & contrast
No heading→paragraph→image repetition. Mix asymmetric grids, oversized type,
split screens, sticky images, big quotes, short statements, stats, horizontal
content, full-bleeds, macro imagery, floating cards, negative space, loops,
overlapping content, subtle parallax. **Never the same composition twice in a
row** — alternate tone and layout section to section.

## 11–12 · Photography is central
Large, confident, real: cultivation, flower, macro/trichomes, roots, whenua,
Hawke's Bay, staff, processing, greenhouse, outdoor, soil, weather. Premium
cannabis **and** connection to place — do not hide the product behind cultural
storytelling. Use 50–100vh visual breaks between heavy sections
(`[FULL-BLEED … — PLACEHOLDER]`).

## 13 · Placeholder rule
Never simplify a design because an asset doesn't exist. Insert a labelled
placeholder stating: asset type, ratio, subject, camera style, intended
animation, purpose.

## 14 · One grid underneath
Consistent max widths, margins, type hierarchy, spacing increments, radii,
buttons, navigation. Creative but controlled.

## 15–16 · Cultural approach & balance
Māori identity through whenua, whakapapa, muka, aho, language, storytelling,
people, photography, material, movement — not decorative motifs everywhere.
Balance aho/whenua/cannabis/cultivation/terroir/science/quality/traceability/
people/values; no theme dominates.

## 17 · Animation language
Slow reveals, thread drawing on scroll, gentle fades/slides, slight parallax,
masked reveals, counting stats. No bouncing, rapid transitions, cursor
gimmicks, or motion that blocks reading. Cinematic, not technological.

## 18–19 · Spacing & typography
Generous vertical space; mix compact / editorial / near-full-screen /
full-screen moments. Keep existing type family; use it boldly — huge
statements, small labels, restrained measures, oversized statistics,
occasional vertical type. No long centred paragraphs.

## 20 · Navigation
Consistent site-wide; hero sits naturally beneath it; optional subtle
you-are-here cue; keep it simple.

## 21 · Mobile is its own design
Keep chapter colours, powerful heroes, simplified vertical thread, fewer
overlaps, generous spacing, large photography. Thread = simple vertical fibre
that occasionally curves toward important content.

## 22 · Accessibility & performance
Strong contrast, reduced-motion support, responsive/lazy media, compressed
video + mobile alternatives, semantic structure, keyboard usable, alt text,
animation never blocks content.

## 23–24 · Endings & footer
Every page closes deliberately: statement / next chapter / Tūhono Mai / CTA /
imagery; thread may run toward the footer and fade. Footer consistent
site-wide, darkest palette, generous spacing — the final chapter, not a
utility block.

## 25 · One connected experience
Clear separation, one continuous story. *Separate chapters. One thread.*
