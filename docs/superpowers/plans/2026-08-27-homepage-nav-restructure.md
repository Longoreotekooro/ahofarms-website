# Aho Farms Homepage Restructure & Two-Tier Bilingual Nav — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the flat navigation with a two-tier bilingual nav modelled on puro.nz, move three duplicated chapters off the homepage into the pages that own them, and create five new pages.

**Architecture:** The nav is defined once as data in `scripts/nav-config.js`, rendered to HTML by `scripts/render-nav.js`, and stamped into every page between sentinel comments by `scripts/propagate-nav.js`. Correctness is enforced by `scripts/check-nav.js`, which resolves every nav href against the real filesystem and against real anchor ids. Pages remain self-contained static HTML with inline CSS — no build step, no framework, no runtime dependency on the scripts.

**Tech Stack:** Static HTML5, inline CSS, vanilla JS. Node.js (built-in modules only — `fs`, `path`) for the tooling scripts. No npm dependencies, no `package.json`.

## Global Constraints

- **Do not modify the hero.** The v5 Matariki film, its `timeupdate` beat sync, autoplay retry chain, and `html.no-video` fallback are untouched. Verify the film still plays after every task that edits `index.html`.
- **No new npm dependencies.** Node built-ins only. There is no `package.json` and none is added.
- **No build step.** Every page must open correctly as a plain file served over HTTP.
- **No fabricated facts.** On `origins.html`, `team.html`, `board.html`, `business.html`: no invented names, titles, bios, dates, qualifications, shareholdings, or company-structure claims. Placeholders must be visibly marked as placeholders in the rendered page.
- **No regulator logos** in the Partnered With Us carousel. Placeholder tiles only.
- **Accessible name stays English.** The te reo label is presentational; screen readers must not see mutating text.
- **Nav must not reflow on hover.** Measured, not eyeballed.
- **Te reo labels are provisional.** Every `mi:` string in `nav-config.js` is a proposal pending review by a fluent speaker. Do not treat them as final.
- Test server: `preview_start` with the `aho-site` launch config, port 8123.

- [ ] **Step 2: Write the failing check**

Create `scripts/check-nav.js`:

```js
const fs = require('fs');
const path = require('path');
const { NAV, CTA, SENTINEL_START, SENTINEL_END } = require('./nav-config');

const ROOT = path.join(__dirname, '..');
const failures = [];

function fail(msg) { failures.push(msg); }

// Collect every href the nav references.
const allLinks = [];
NAV.forEach(p => { allLinks.push(p.href); p.children.forEach(c => allLinks.push(c.href)); });
allLinks.push(CTA.href);

// 1. Every href resolves: file exists, and if it has a #anchor, that id exists in the file.
[...new Set(allLinks)].forEach(href => {
  const [file, anchor] = href.split('#');
  const full = path.join(ROOT, file);
  if (!fs.existsSync(full)) { fail(`MISSING FILE: ${href} -> ${file}`); return; }
  if (anchor) {
    const html = fs.readFileSync(full, 'utf8');
    if (!html.includes(`id="${anchor}"`)) fail(`MISSING ANCHOR: ${href} (no id="${anchor}" in ${file})`);
  }
});

// 2. Every page carries exactly one sentinel-delimited nav block.
const pages = fs.readdirSync(ROOT).filter(f => f.endsWith('.html'));
pages.forEach(p => {
  const html = fs.readFileSync(path.join(ROOT, p), 'utf8');
  const starts = html.split(SENTINEL_START).length - 1;
  const ends = html.split(SENTINEL_END).length - 1;
  if (starts !== 1 || ends !== 1) fail(`BAD SENTINELS: ${p} (start=${starts} end=${ends}, expected 1/1)`);
});

// 3. No page links to a file that does not exist.
pages.forEach(p => {
  const html = fs.readFileSync(path.join(ROOT, p), 'utf8');
  const hrefs = [...html.matchAll(/href="([^"#:]+\.html)(?:#[^"]*)?"/g)].map(m => m[1]);
  [...new Set(hrefs)].forEach(h => {
    if (!fs.existsSync(path.join(ROOT, h))) fail(`DEAD LINK: ${p} -> ${h}`);
  });
});

if (failures.length) {
  console.error(`FAIL (${failures.length}):`);
  failures.forEach(f => console.error('  ' + f));
  process.exit(1);
}
console.log(`PASS - ${pages.length} pages, ${new Set(allLinks).size} nav targets, all resolve.`);
```

- [ ] **Step 4: Write the renderer**

Create `scripts/render-nav.js`:

```js
const { NAV, CTA } = require('./nav-config');

const esc = s => s.replace(/&/g, '&amp;').replace(/</g, '&lt;').replace(/>/g, '&gt;');

// Bilingual label: both languages in one grid cell, sized to the wider.
// aria-label pins the accessible name to English so it never mutates.
function label(item) {
  return `<span class="bil"><span class="bil-en">${esc(item.en)}</span>` +
         `<span class="bil-mi" aria-hidden="true">${esc(item.mi)}</span></span>`;
}

function isActive(href, currentPage) {
  return href.split('#')[0] === currentPage;
}

function renderNav(currentPage) {
  // Which parent owns the current page? Defaults to Learn (index 0).
  let activeIdx = 0;
  NAV.forEach((p, i) => {
    if (p.children.some(c => isActive(c.href, currentPage)) || isActive(p.href, currentPage)) activeIdx = i;
  });
  // A childless parent cannot populate the bar - fall back to Learn.
  if (!NAV[activeIdx].children.length) activeIdx = 0;

  const parents = NAV.map((p, i) => {
    const caret = p.children.length ? '<span class="nav-caret" aria-hidden="true"></span>' : '';
    const hasKids = p.children.length ? ' data-haskids="1"' : '';
    return `<li class="nav-parent${i === activeIdx ? ' is-active' : ''}"${hasKids} data-idx="${i}">` +
           `<a href="${p.href}" aria-label="${esc(p.en)}">${label(p)}${caret}</a></li>`;
  }).join('\n        ');

  const bars = NAV.map((p, i) => {
    if (!p.children.length) return '';
    const kids = p.children.map(c =>
      `<li><a href="${c.href}" aria-label="${esc(c.en)}">${label(c)}</a></li>`
    ).join('\n            ');
    return `<ul class="nav-sub" data-for="${i}"${i === activeIdx ? '' : ' hidden'}>\n            ${kids}\n          </ul>`;
  }).filter(Boolean).join('\n          ');

  return `<nav class="nav" id="nav" aria-label="Main">
    <div class="nav-inner">
      <a href="index.html" class="nav-logo">AHO <em>FARMS</em></a>
      <button class="nav-burger" aria-expanded="false" aria-controls="navDrawer" aria-label="Menu">
        <span></span><span></span><span></span>
      </button>
      <ul class="nav-links" id="navDrawer">
        ${parents}
        <li class="nav-cta-wrap"><a href="${CTA.href}" aria-label="${esc(CTA.en)}">${label(CTA)}</a></li>
      </ul>
    </div>
    <div class="nav-bar2">
      <div class="nav-bar2-inner">
          ${bars}
      </div>
    </div>
  </nav>`;
}

module.exports = { renderNav };
```

```js
(function(){
  const nav = document.getElementById('nav');
  if (!nav) return;
  const burger = nav.querySelector('.nav-burger');
  const links = nav.querySelector('.nav-links');
  if (!burger || !links) return;

  // Clone each sub-list into its parent so the accordion has something to expand.
  nav.querySelectorAll('.nav-bar2 .nav-sub').forEach(sub => {
    const parent = nav.querySelector(`.nav-parent[data-idx="${sub.dataset.for}"]`);
    if (parent && !parent.querySelector('.nav-sub')) {
      const clone = sub.cloneNode(true);
      clone.removeAttribute('hidden');
      parent.appendChild(clone);
    }
  });

  burger.addEventListener('click', () => {
    const open = links.classList.toggle('is-open');
    burger.setAttribute('aria-expanded', String(open));
    document.body.style.overflow = open ? 'hidden' : '';
  });

  // On touch widths, first tap expands rather than navigates.
  nav.querySelectorAll('.nav-parent[data-haskids] > a').forEach(a => {
    a.addEventListener('click', e => {
      if (window.matchMedia('(max-width:900px)').matches) {
        const li = a.closest('.nav-parent');
        if (!li.classList.contains('is-expanded')) { e.preventDefault(); li.classList.add('is-expanded'); }
      }
    });
  });
})();
```

### Task 9: Propagate nav and unified footer across all pages

**Files:**
- Create: `scripts/propagate-nav.js`
- Modify: all 25 `.html` pages

**Interfaces:**
- Consumes: `renderNav` (Task 1), the CSS contract (Task 2), all pages created in Tasks 4-5.
- Produces: every page carrying one sentinel-delimited nav and one footer variant.

- [ ] **Step 1: Write the propagation script**

Create `scripts/propagate-nav.js`:

```js
const fs = require('fs');
const path = require('path');
const { renderNav } = require('./render-nav');
const { SENTINEL_START, SENTINEL_END } = require('./nav-config');

const ROOT = path.join(__dirname, '..');
const esc = s => s.replace(/[.*+?^${}()|[\]\\]/g, '\\$&');
const pages = fs.readdirSync(ROOT).filter(f => f.endsWith('.html'));
const RE = new RegExp(esc(SENTINEL_START) + '[\\s\\S]*?' + esc(SENTINEL_END));

let stamped = 0, seeded = 0;
pages.forEach(p => {
  let html = fs.readFileSync(path.join(ROOT, p), 'utf8');
  const block = SENTINEL_START + '\n' + renderNav(p) + '\n' + SENTINEL_END;
  if (RE.test(html)) { html = html.replace(RE, block); stamped++; }
  else {
    // Seed: replace the page's existing <nav>...</nav>, whatever shape it is.
    const old = html.match(/<nav[\s\S]*?<\/nav>/);
    if (!old) { console.warn(`SKIP (no <nav> found): ${p}`); return; }
    html = html.replace(old[0], block); seeded++;
  }
  fs.writeFileSync(path.join(ROOT, p), html);
});
console.log(`stamped ${stamped}, seeded ${seeded}, total ${pages.length}`);
```

Idempotent: re-running replaces between sentinels rather than nesting.

The script rewrites 25 files. Ensure `git status` is clean so the diff is reviewable and revertible.
