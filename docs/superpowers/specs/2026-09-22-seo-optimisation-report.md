# Aho Farms — Website Audit, SEO & Optimisation Report

Date: 2026-09-22. Live site: https://ahofarms-website.vercel.app (custom
domain not yet attached). Builds on the earlier audit report of the same
day (`2026-09-22-website-audit-report.md`) and the security review; this
document is the consolidated final report the brief asks for.

## 1. Summary of what was reviewed

- Every public page (21) and the Consumer Portal journey, plus the hidden
  portal routes, at 375, 768, 1024, 1280 and 1600 px.
- Header, dropdowns, mobile accordion, footer, Connect sheet, all forms.
- Typography, tokens, spacing, motion, focus states, reduced motion.
- Metadata: titles, descriptions, canonicals, Open Graph, Twitter cards,
  favicon, robots.txt, sitemap.xml, structured data.
- Links (internal and external), heading hierarchy, images, video, fonts.
- Serverless code: auth, sessions, rate limiting, input validation, mail,
  headers, exposure of server files.
- Tooling: `scripts/audit-site.js`, `check-nav.js`, `check-launch.js`,
  browser measurement at each width, live verification after deploy.

## 2. Issues discovered

Critical (fixed today unless marked)

- The contact form and the newsletter form had no backend. Both showed a
  "thank you" message and discarded the submission.
- Nine "Read more" links on News pointed at `#`.
- Mail transport is not configured on Vercel, so every notification
  (consumer leads, contact messages, subscriptions) is logged, not sent.
  **Not fixable in code; needs environment variables (see section 11).**

High

- No structured data on any page.
- Heading order broke on every page: footer columns used `h5` after `h2`
  sections; home jumped `h2 → h4`; products, news and contact jumped
  `h1 → h3`; a cultivation list used `h4` under `h2`.
- Titles mixed three patterns; two public pages carried the boilerplate
  description.
- No cross-links between About, the Aho Advantage, Terroir, Products and
  Quality beyond the header.
- No security headers other than HSTS; server modules and build scripts
  were served as public files; the login rate limiter failed open and is
  per-instance without Redis.

Medium and low

- Sessions cannot be revoked before expiry (see section 9).
- News articles have no detail pages (the reason the links were dead).
- Two informational pages (Kaupapa, Social Impact) are `noindex` by an
  earlier decision; they now have unique descriptions but remain excluded
  from search pending a decision (section 11).
- The desktop hero film (10 MB) and Matariki film (3.9 MB) are heavy; no
  encoder is available locally.

## 3. Changes implemented

Forms

- New endpoints `POST /api/contact/send` and `POST /api/newsletter/subscribe`:
  server-side validation with per-field errors, honeypot, rate limit (6 per
  hour per connection), same-origin check. Contact messages email
  `CONTACT_TO` (default admin@ahofarms.com). Subscriptions are stored in the
  Redis store when configured and notify `NEWSLETTER_TO` (falls back to
  `CONTACT_TO`).
- Both forms now show loading, field-level error and success states, keep
  keyboard focus on the first error, and announce results to screen readers.
- Consumer Portal enquiries continue to route to admin@ahofarms.com (and
  korijames@ahofarms.com); this destination was not changed.

SEO

- Organization + WebSite JSON-LD on the home page (name, URL, logo, region
  and country, social profiles: only facts the site already states).
- BreadcrumbList JSON-LD on every indexable page, generated by the chrome
  script so new pages get it automatically; noindex pages are excluded.
- Titles normalised to `Topic | Aho Farms` on home, About and Products,
  with matching Open Graph and Twitter titles.
- Unique descriptions for Kaupapa and Social Impact.
- Dead News links removed; hidden Prescriber page sign-in link corrected.
- Cross-links added in the existing link style: About → Aho Advantage,
  Advantage → Terroir, Terroir → Products, Quality → Products.
- Sitemap regenerated (16 URLs, no hidden or noindex pages).

Headings

- Footer column labels are `h2` with the same visual style. Home portal
  rows and news cards are `h3`; product range cards, news cards and contact
  cards are `h2`; the cultivation journey list uses `h3`. All CSS moved with
  the tags, and computed sizes were checked in the browser to confirm no
  visual change.

Security

- Headers on every response: `X-Content-Type-Options: nosniff`,
  `X-Frame-Options: DENY`, `Referrer-Policy: strict-origin-when-cross-origin`,
  a `Permissions-Policy`, and an enforced Content Security Policy
  (self plus Google Fonts, image hosts and the Instagram feed; frames denied).
- `/lib/*`, `/scripts/*` and `portal-flags.json` now return 404 on the live
  site.
- The auth rate limiter fails closed on login, forgot and reset; admin API
  errors no longer echo raw store errors.

## 4. Critical pre-launch issues

1. Set the mail transport on Vercel (`RESEND_API_KEY`, `MAIL_FROM`). Until
   then no enquiry, contact message or subscription reaches an inbox.
2. Add the Upstash Redis store and `SESSION_SECRET`. Without Redis, leads
   and subscribers live in function memory and rate limits are not shared.
3. Add New Zealand and Australia prescriber partners so consumer enquiries
   get a referral rather than "our team will contact you".
4. Attach the custom domain and update `site.json`, then rebuild, so
   canonicals, Open Graph URLs and the sitemap stop pointing at the Vercel
   host.

## 6. Performance improvements

Carried over from the morning pass and still in effect: six photographs
resized (3.9 MB → 2.1 MB), width and height on 23 images, lazy loading below
the fold, favicon 404 removed, three synthesised font weights eliminated,
fonts preconnected with `display=swap`, immutable caching on `/assets/`.
Today's pass added no page weight: the JSON-LD blocks are under 1 KB each
and the form scripts are inline and small.

## 7. Desktop, tablet and mobile

No layout changes were needed today. Verified again after the heading and
link changes: contact form errors and newsletter confirmation on a 375 px
phone; footer headings unchanged at 375 and 1280; product hero cards,
home portal rows and news cards unchanged in size and typeface; new
cross-links render at 44 px touch height in the accent colour.

## 8. Global style improvements

- One footer heading class (`aho-footer-h`) replaces tag-based styling.
- One small utility (`aho-next`) spaces the cross-links consistently.
- Form error colour and message styles added to the two hand-built forms
  using the same treatment as the portal forms.

## 9. Recommendations not yet implemented

- **News article pages**: give each news item a permanent page so the
  cards can link somewhere and the items can carry `NewsArticle` schema.
  Removed the dead links rather than invent destinations.
- **Session revocation**: add a per-user session version checked by the
  dashboard and admin APIs so suspending an account ends its sessions; also
  shorten "remember me" from 30 to 7 days. Matters once professional
  portals launch.
- **Extensionless URLs** (`/about` instead of `/about.html`): Vercel
  `cleanUrls` would do this with 308 redirects, but every internal link,
  canonical and sitemap entry would need updating together. Do it before
  the domain goes live if wanted, not after.
- **Modern image formats** (WebP/AVIF) and **video re-encode** of the two
  large films, where an encoder is available.
- **CSS consolidation** of page-level styles to three breakpoints; too
  broad to do safely right before launch.
- **CSP hardening**: the policy allows inline scripts because every page
  has them; moving to nonces is a post-launch job.
- **Product, FAQ and Article schema**: not added. Products are
  prescription-only and not sold on the site, Google limits FAQ rich
  results to government and health authorities, and news items have no
  pages. Adding them now would be misleading or unrewarded.
- **Apple touch icon and a PNG logo** for the Organization schema once
  produced from the mark.
- **Terminology**: "Customers" (header) versus "Consumer Portal" (page,
  footer). Both are approved copy; flagged for a decision.

## 10. Remaining risks

- Email delivery is unconfigured (section 4). This is the single biggest
  launch risk: forms work but nobody receives the messages.
- Mailbox domains: the site displays `@ahofarms.co.nz` addresses while
  operations use `@ahofarms.com`. If the `.co.nz` mailboxes are not live,
  visitors emailing them get no reply.
- Canonicals point at the Vercel host until the domain is attached.
- Behold Instagram feed is not configured (`data-behold-feed` is empty), so
  the What's New grid shows static tiles.
- Without Redis, a redeploy clears leads and subscribers and the login
  limiter is per instance.

## 12. Recommended next steps

1. Set the five Vercel environment variables (mail, Redis, session) and
   test the contact form and Consumer Portal end to end.
2. Confirm the live mailboxes and update contact copy if the `.co.nz`
   addresses are not real.
3. Add the NZ and AU prescriber partners via `scripts/portal-admin.js`.
4. Attach the domain, update `site.json`, rebuild, redeploy, then verify
   the property in Search Console and submit the sitemap.
5. Decide on extensionless URLs before the domain goes public.

## 13. 30–90 day optimisation plan

Days 1–30

- Complete section 12. Verify Search Console; fix any coverage errors.
- Produce the OG image and PNG logo; add the Apple touch icon.
- Write and publish the nine news article pages with `NewsArticle` schema.
- Start P1 backlink outreach (see `2026-09-22-backlink-strategy.md`).
- Configure the Behold Instagram feed.

Days 31–60

- Re-encode the hero films; add WebP sources for the largest photographs.
- Implement session revocation and shorter "remember me" ahead of the
  professional portal launch.
- Review Core Web Vitals field data in Search Console; address any LCP or
  CLS regressions with real-user numbers rather than lab guesses.
- Decide and act on indexing for Kaupapa, Social Impact and Team.

Days 61–90

- CSS consolidation pass (three breakpoints, shared hero and card
  patterns).
- CSP nonces to remove `unsafe-inline`.
- Analytics review: which pages lead to Consumer Portal enquiries; adjust
  internal links and CTAs from evidence.
- P2 backlink outreach; first quarterly backlink review.
- Prepare the Prescriber and Pharmacy portals for staged release with the
  same launch checks used for the Consumer Portal.
